# Security

Study Tracker stores data locally and does not provide cloud synchronization or user accounts. Keep the Windows account and device holding the database protected, and make backups in a location you trust.

Please do not include a real database, backup, session notes, or other personal study information in a bug report. If you find a security issue, contact the repository maintainer privately before making it public. A public vulnerability-reporting channel should be configured on the repository hosting service before the project is announced broadly.
